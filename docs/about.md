# About

This repository is the personal GitHub Pages site of
[Kirill Vassiljev](https://github.com/KirillVassiljev). It serves as a sample
MkDocs project you can copy and adapt.

## Stack

- [MkDocs](https://www.mkdocs.org/) — static site generator for documentation
- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) — theme
- [GitHub Actions](https://docs.github.com/actions) — build and deploy
- [GitHub Pages](https://pages.github.com/) — hosting

## Layout

```text
.
├── docs/
│   ├── index.md
│   ├── about.md
│   ├── guide/
│   └── stylesheets/
├── mkdocs.yml
├── requirements.txt
└── .github/workflows/deploy.yml
```
