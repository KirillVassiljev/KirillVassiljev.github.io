# Welcome

This is a sample documentation site built with [MkDocs](https://www.mkdocs.org/)
and the [Material](https://squidfunk.github.io/mkdocs-material/) theme, published
automatically to GitHub Pages.

!!! tip "Start here"
    New to the project? Head over to [Getting started](guide/getting-started.md).

## What's inside

<div class="grid cards" markdown>

- **Guide** — how to install, run, and configure the site.
- **About** — what this project is and who maintains it.

</div>

## Features

- Live-reloading local preview with `mkdocs serve`
- Full-text search
- Light and dark colour schemes
- Code blocks with syntax highlighting and a copy button
- Automatic deployment on every push to `main`

## Quick preview

```bash
uv run --with mkdocs-material mkdocs serve
```

Then open <http://127.0.0.1:8000>.
